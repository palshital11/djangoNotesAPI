# djangoNotesAPI

A simple and clean **Notes CRUD REST API** built using Django and Django REST Framework.  
Users can register, log in, and manage personal notes securely.

---

## 🚀 Features
- User Registration & Login
- Token-based Authentication
- Create, Read, Update, Delete Notes
- Pagination & Filtering
- Proper Status Codes & Error Handling
- Modular, scalable Django project structure
- Postman Collection included

---

## 🛠 Tech Stack
- Python
- Django
- Django REST Framework (DRF)
- SQLite / PostgreSQL
- Postman
